# 📌 Project Overview

This project presents an intelligent autonomous drone capable of:

- 🚀 Autonomous flight navigation
- 🧠 Intelligent obstacle avoidance
- 🎯 Reinforcement Learning using PPO
- 👁️ Real-time object detection
- 📡 Flight state monitoring
- 💬 Human-readable flight narration
- 📈 Training and evaluation framework

The system continuously analyzes the environment, detects nearby obstacles, predicts safe flight actions, and explains every navigation decision in real time.

# 🚀 Installation

Clone the repository

```bash
git clone https://github.com/Arwa-Hamdy-Mohammdy/DEPI_Project.git
```

Move into the project

```bash
cd DEPI_Project
```

Install dependencies

```bash
pip install -r requirements.txt
```

---

# ▶️ Running the Project

Run the autonomous drone system

```bash
python main.py
```

Train the PPO model

```bash
python train.py
```
